### 🚀 Featured project

**[AI-Driven DevSecOps Platform](https://github.com/souhaiel11/pfe-platform-2026)** — final-year project at Vermeg
- Multi-agent AI workflows (n8n) analyse SonarQube, Trivy, OWASP and ZAP findings on every Jenkins build
- AI proposes fixes as GitHub PRs — **only after human approval**
- Deterministic, auditable security score instead of an LLM score
- Every fix is rebuilt and re-scanned in an isolated sandbox before reaching Git
- Deployment to Azure (Terraform, ACR, ACI)
